# Nic Bailey Racing — More Than Racing

A mobile-friendly, static karting team website for GitHub Pages.

## Publish on GitHub Pages

1. Create a new **public** repository at https://github.com/new (for example, `nic-bailey-racing`).
2. Upload **all six website files** from this folder, plus `.nojekyll` and this README, to the repository root. Do not upload the ZIP as the only file.
3. Commit the files to the `main` branch.
4. Open repository **Settings → Pages → Build and deployment**. Select **Deploy from a branch**, `main`, and `/ (root)`, then Save.
5. Wait for deployment. The website address will look like `https://YOUR-USERNAME.github.io/nic-bailey-racing/` (replace both placeholders). You can find the actual link under Settings → Pages.

## Pages

- `index.html` — Homepage, beginner guide, team story, sponsor information
- `paddock.html` — Blog preview
- `videos.html` — Video gallery preview
- `style.css` — Shared page styling
- `posts.js` — Blog preview behavior
- `videos.js` — Video preview behavior

## Important: posting and contact

The blog and video submission forms **only save to your own browser's local storage**. They do not publish posts for other visitors. GitHub Pages does not provide a database, user accounts, or a private admin dashboard. To publish updates publicly, add them to the repository content or integrate a CMS/backend in a future version.

The homepage's contact link is a placeholder `mailto:` link without a recipient. Replace it with your actual public contact email or a hosted contact form before sharing the site widely.

## Customize

Search for `Nic Bailey Racing` in the HTML files to change the temporary site name. Add real driver photos, sponsor logos, and confirmed race dates before promoting the site. Relative links are used so it works in a GitHub Pages project repository.
